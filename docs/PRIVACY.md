# 分发内容与隐私边界

本仓库只分发通用截图审阅工具，不包含实际产品的设计稿、开发页面截图、审阅包、个人批注、测试账号或业务数据。

## 两种制品

| 制品 | 内容 | 本仓库是否分发 |
| --- | --- | --- |
| 技能安装包 | SKILL.md、静态模板、Python/PowerShell 脚本、通用参考说明 | 是 |
| 业务审阅包 | 实际 PNG、业务清单、页面数据、可选 PDF、用户批注 | 否，保留在所属项目本地 |

README 和文档使用通用清单，以及六张专门拍摄的虚构示例说明图。Luma Board 的页面、文字和数据全部来自 `examples/fictional-app.html`；浏览器先渲染这些虚构页面，再用本工具打开其截图，拍摄功能界面。详细来源见[实拍指南](SCREENSHOTS.md)。

这六张图片是工具实际运行的截图，未使用开发者的设计图或开发页面；允许分发的路径、尺寸及 SHA-256 记录在 `docs/images/provenance.json`。完整临时采集图和演示审阅包不进入仓库。`examples/create_demo.py` 仍只在运行时生成抽象色块。

## 运行时数据

- 生成器只读取当前任务清单明确列出的 PNG，可选读取调用者指定的 PDF。
- 静态审阅页不加载 CDN、分析统计或第三方请求脚本；截图通过当前离线目录或本机服务加载。
- 文字意见、状态和标点保存在当前浏览器；导出的 Markdown/JSON 保存为本地文件。
- 本地服务仅监听回环地址。部署审阅内容或把业务审阅包传给他人需要单独决定。

## 发布检查

`scripts/check_distribution.py` 使用明确文件白名单检查源码仓库，并检查安装 ZIP：

- 仓库只允许维护清单中的文本文件，以及六个明确列出的虚构示例 JPEG；安装 ZIP 仍只允许 `screenshot-review/` 下的技能文本资源。
- 文档 JPEG 必须匹配来源记录中的尺寸和 SHA-256，且不携带 EXIF/IPTC/注释元数据；虚构应用源码哈希也参与检查。
- 其他图片、设计文件、PDF、真实审阅输出、未知文件、符号链接或其他二进制均不接受。
- 拒绝内嵌图片/PDF 数据、可疑的大段编码数据和个人用户目录路径。
- Git 仓库检查全部已跟踪文件；发布安装包检查 ZIP 中的每个条目。

`.gitignore` 排除本地生成的输出、截图、PDF 和批注备份，仅为这六张已检查的说明图设置精确例外。白名单和来源哈希用于减少误上传，不能自动判断画面是否虚构；新增图片仍需逐张核对内容和采集来源。

## 维护约定

发布仓库从工具文件清单单独组装，不复用业务仓库历史。GitHub README、Issue、PR、Release 附件和 CI 制品均沿用同一边界；演示需要截图时，只使用可公开的专门示例，不引用开发项目现有页面。
